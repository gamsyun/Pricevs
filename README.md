# 购物因素 PriceVS
You can find the best price by using this Web.<br>
通过此网址找到最划算的商品。<br>
You can open the URL in Safari on your iPhone, then tap "Add to Home Screen" to use it as a WEB APP（PWA）.<br>
在iPhone Safari中打开网址，之后点选「添加至主屏幕」可使其以Web App形式使用。<br>
PriceVS will disguise more like an app if you wait a little moment after tapping the button "Add to..." until the icon is loaded：)<br>
在点选「添加至……」后稍做等待，购物因素PriceVS的标志就会加载出来，这看上去会更像一个App(:))。
